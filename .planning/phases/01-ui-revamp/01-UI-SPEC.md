# Phase 1 — UI Design Contract: AstroVetro Complete Visual Redesign

> Visual and interaction contract for the AstroVetro complete frontend redesign. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Source authority:** This contract is the creative brief. Every locked decision below is **mandatory** — not aspirational. Real business data is pulled from `src/data/*` and must not be invented or overwritten. The current `index.css` tokens and all component visuals must be **completely replaced** — this is a ground-up rebuild, not a recolor.

## Design System

| Property | Value |
|----------|-------|
| Tool | **none** (bespoke Tailwind v4 CSS-first system; no shadcn) |
| Preset | not applicable |
| Component library | none (hand-rolled editorial components) |
| Icon library | none (minimal inline SVG / unicode arrows only — avoid icon-library look) |
| Font | **Instrument Serif** (display serif) + **Manrope** (sans) |
| Styling | Tailwind v4 CSS-first `@theme` tokens in `src/index.css` |

**shadcn gate decision:** The brief explicitly forbids generic "AI-generated template" look, excessive rounded rectangles, and overuse of cards. shadcn's conventions conflict with the required bespoke luxury-editorial art direction. `components.json`, `tailwind.config.*`, and `postcss.config.*` are **absent**. **Decision: Tool = none.** No registry safety vetting required.

### Typography

**Fonts:** `Instrument Serif` (display) + `Manrope` (sans) — loaded via Google Fonts or self-hosted. Replace the current Cormorant Garamond / DM Sans pairing entirely.

| Role | Font | Sizes (px) | Weight | Line Height |
|------|------|-----------|--------|-------------|
| Display | Instrument Serif | 96, 72, 56 | 400 (regular) | 1.0–1.05 |
| Heading | Instrument Serif | 40, 32 | 400 | 1.1 |
| Subheading | Instrument Serif *italic* | 28 | 400 | 1.2 |
| Body | Manrope | 16, 18 | 400 | 1.5 |
| Lead | Manrope | 20 | 400 | 1.5 |
| Label / Caption | Manrope | 12, 14 | 500 | 1.4 |
| Micro-metadata | Manrope | 10–11 | 500 | 1.3, letterspacing 0.18em, uppercase |

**Typographic rules:**
- Exactly **2 weights**: 400 (regular) + 500/600 (semibold) for CTAs/labels. Never 700+.
- Display headlines use **unusual line breaks**: `THE / UNIVERSE / LEFT / SOMETHING / FOR YOU.` — not flowing paragraphs.
- Body max-width ~60–70ch. Narrow editorial columns, not wide blocks.
- Do NOT make every section centered. Use asymmetric alignments.
- Uppercase reserved for micro-metadata and CTAs only.
- Typography is one of the **primary visual elements** — massive, expressive, editorial.

### Spacing Scale (multiples of 4)

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing |
| lg | 24px | Card padding, inner section gaps |
| xl | 32px | Layout gaps, feature blocks |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |
| 4xl | 96px | Big section rhythm (desktop only) |
| section-y | 120px (desktop) / 72px (mobile) | Vertical padding of major `<section>` elements |

**Exceptions:** Icon/touch targets ≥ 44px. Hero uses asymmetric large whitespace (not uniform spacing box).

### Border Radius System — minimal, architectural

| Token | Value | Usage |
|-------|-------|-------|
| `--radius-none` | 0 | Editorial grid frames, full-bleed imagery |
| `--radius-sm` | 4px | Small chips, small buttons |
| `--radius-md` | 8px | Cards, image frames |
| `--radius-lg` | 16px | Large image frames only |
| `--radius-full` | 999px | Pill buttons |

**Rule:** Prefer 0–8px for most surfaces. Reserve large radii for select moments. Avoid rounded-everything.

### Shadows / Elevation

| Token | Value |
|-------|-------|
| `--shadow-soft` | 0 1px 2px rgba(23,19,29,0.04), 0 8px 24px rgba(23,19,29,0.05) |
| `--shadow-lift` | 0 2px 6px rgba(23,19,29,0.06), 0 24px 64px rgba(23,19,29,0.10) |

### Motion / Timing

| Token | Value |
|-------|-------|
| `--ease-out-expo` | cubic-bezier(0.16, 1, 0.3, 1) |
| Standard reveal | 0.9–1.4s ease-out-expo |
| Hover | 0.3s ease |
| Stagger | 0.08–0.12s per child |
| Parallax | gentle, ≤ 20% of scroll delta |

**Motion mood:** SMOOTH, EXPENSIVE, CONTROLLED, EDITORIAL. Not fast, not gamified, not neon. **Must** respect `prefers-reduced-motion` (framer-motion `useReducedMotion` + CSS reduce block).

**Animation language:** scroll reveals, image clipping (clip-path), text splitting, parallax, hover scaling, magnetic buttons, colour transitions, marquee typography, orbital motion. Avoid: bouncing, spinning logos, constant floating, excessive blur, random particle systems.

### Background Texture

**Do not** use a flat background throughout. Add subtle texture:
- Paper grain, fine noise, or very subtle halftone
- Applied extremely subtly — **felt, not noticed**
- CSS-only (pseudo-element with noise SVG or subtle repeating pattern)
- Opacity ≤ 3%

## Layout / Grid System

### Breakpoints

| Breakpoint | Width | Notes |
|------------|-------|-------|
| Mobile | 375, 390, 430px | Intentionally composed, no horizontal overflow |
| Tablet | 768px | Split layouts begin |
| Laptop | 1024px | Editorial columns |
| Desktop | 1280, 1440px | Expansive |
| Wide | 1920px | Full-bleed interludes |

### Grid

- **Editorial grid:** 12-column max-w-7xl (~80rem), generous gutters (px-6 mobile → lg:px-10).
- **Do NOT use a perfect uniform grid.** Use: asymmetry, overlap, variable image sizes, large margins, unexpected alignments, editorial columns, sticky sections, horizontal moments.
- Thin 1px grid lines at very low opacity (ink/5) in selected sections only — scientific/architectural drafting feel.
- Sporadic micro-metadata: `01`, `02`, `03` and `ASTROVETRO / 01`, `COLLECTION / 02` numerals in micro-uppercase — sparse, top corners of sections.

**CHAOS SHOULD APPEAR. ACTUAL CHAOS SHOULD NOT EXIST.**

### Image Aspect Ratios

| Use | Ratio |
|-----|-------|
| Hero (major) | 4:5 or 3:4 cinematic portrait |
| Product primary | 1:1 square, or 4:5 for jewellery |
| Featured product spotlight | 3:4 portrait |
| Service/reading | 3:4 portrait |
| Editorial / journal | 3:4 or 4:5 |
| Interlude / full-bleed | 16:9 or 4:3 |

**Image treatment:** cropping, overlap, masking, rounded irregular shapes, full-bleed, editorial cutouts, collages, oversized photography. Never generic rectangular blocks everywhere. Responsive images with `srcset`, lazy loading below fold, hero preload.

## Responsive Design

Rebuild properly for: 375, 390, 430, 768, 1024, 1280, 1440, 1920px.

**Do NOT simply stack desktop sections on mobile.** Create intentional mobile compositions. Mobile must still feel bold, colourful, editorial, premium — without horizontal overflow. Full-bleed interludes crop gracefully (object-cover + srcset).

---

## Accessibility

- Semantic HTML, keyboard navigation, visible focus states
- Accessible contrast: ink on ivory AA-safe; ink-soft on ivory AA for ≥14px
- `prefers-reduced-motion` respected (framer-motion `useReducedMotion` + CSS reduce block)
- Meaningful alt text on all imagery
- Intention explorer keyboard accessible

---

## Performance

- AVIF/WebP derivatives, responsive `srcset`, lazy loading (below fold), hero preload
- Explicit `width`/`height` on all images
- CSS transforms + opacity preferred over JS animation
- IntersectionObserver for scroll reveals
- GPU-friendly animation (transform, opacity only)
- Avoid expensive continuous JavaScript animation loops
- DOM complexity kept reasonable
